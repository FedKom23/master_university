# Обзор литературы и аналогов

> Анализ существующих решений на рынке проверки цен на лекарства

## 1. Нормативная база

1. Федеральный закон РФ № 61-ФЗ «Об обращении лекарственных средств».
2. Постановления Правительства РФ о государственном регулировании цен на жизненно необходимые и важнейшие лекарственные препараты (ЖНВЛП).
3. Государственный реестр лекарственных средств (ГРЛС):
   https://grls.rosminzdrav.ru/
4. Реестр предельных отпускных цен:
   https://grls.rosminzdrav.ru/PriceLims.aspx
5. Налоговый кодекс РФ (в части регулирования НДС на лекарственные средства).

## 2. Исследования в области регулирования цен на лекарства

1. Материалы Минздрава РФ по государственному регулированию цен.
2. Аналитические отчеты DSM Group о фармацевтическом рынке России.
3. Публикации Высшей школы экономики по экономике здравоохранения.
4. Исследования Всемирной организации здравоохранения (WHO) по контролю цен на лекарственные средства.

## 3. Технологические источники

1. Lewis, P. et al. (2020). Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks.
2. Документация OpenAI по LLM и Retrieval-Augmented Generation (RAG).
3. Документация LangChain / LlamaIndex.
4. Best practices построения RAG-систем (FAISS, vector DB).

## 4. Практические кейсы

1. Зарубежные сервисы проверки цен на лекарства (GoodRx, Drugs.com).
2. Государственные цифровые сервисы в сфере здравоохранения (Госуслуги, ЕМИАС).
