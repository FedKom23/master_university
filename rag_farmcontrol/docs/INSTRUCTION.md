# Инструкция по запуску проекта

## Требования

- Python 3.10
- [Ollama](https://ollama.com) — для LLM-ответов (опционально, есть fallback)

---

## Шаг 0. Создать виртуальное окружение

> Нужно сделать один раз.

```bash
python3.10 -m venv venv_faiss
```

---

## Шаг 1. Активировать виртуальное окружение

```bash
source venv_faiss/bin/activate
```

---

## Шаг 2. Установить зависимости

> Нужно сделать один раз.

```bash
pip install -r requirements.txt
```


---

## Шаг 3. Построить поисковые индексы

> Нужно сделать один раз (или повторно при обновлении данных).

```bash
python3.10 engine.py
```

Скрипт читает `data/medicines.xlsx` и создаёт четыре файла в папке `data/`:

| Файл | Содержимое |
|------|-----------|
| `faiss_index.bin` | Векторный индекс (dense-поиск) |
| `bm25_index.pkl` | BM25-индекс (keyword-поиск) |
| `metadata.pkl` | Метаданные всех записей реестра |
| `corpus_tokenized.pkl` | Токенизированный корпус для BM25 |

Построение занимает несколько минут (загрузка модели + кодирование ~51 000 записей).

---

## Шаг 4. Запустить Ollama (опционально)

Ollama нужен для генерации текстового ответа. Если он недоступен — приложение показывает шаблонный ответ и не падает.

```bash
# В отдельном терминале:
ollama serve

# Загрузить модель (один раз):
ollama pull llama3.2:3b
```

---

## Шаг 5. Запустить приложение

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`.

---

## Использование

1. В поле **«Информация о лекарстве»** введите название препарата — МНН или торговое, можно с формой выпуска и дозировкой.
   > Примеры: `аспирин кардио 100мг`, `Панадол таблетки`, `амоксициллин`

2. В поле **«Цена (руб.)»** введите цену, которую хотите проверить.

3. Нажмите **«Проверить цену»**.

**Возможные результаты:**
- ✅ Цена в норме — ниже предельной цены по реестру
- ⚠️ Превышение цены — показывается процент превышения
- Лекарство не найдено — препарат отсутствует в реестре ЖНВЛП

## Структура проекта

```
farmcontrol/
├── data/
│   ├── medicines.xlsx        # Реестр ЖНВЛП Минздрава РФ
│   ├── faiss_index.bin       # Генерируется через engine.py
│   ├── bm25_index.pkl        # Генерируется через engine.py
│   ├── metadata.pkl          # Генерируется через engine.py
│   └── corpus_tokenized.pkl  # Генерируется через engine.py
├── models/                   # Кеш SentenceTransformer (скачивается автоматически)
├── venv_faiss/               # Виртуальное окружение Python 3.10
├── engine.py                 # Построение индексов
├── testing.py                # Тестовые поисковые запросы
├── app.py                    # Streamlit-приложение
└── ragas_test/
    ├── evaluate_rag.py       # Оценка RAG-пайплайна (BLEU + Semantic Similarity)
    └── results.json          # Результаты последнего прогона (генерируется)
```

---

---

## Шаг 6. Оценить качество RAG (опционально)

Запускает оценку поискового пайплайна на тестовом датасете, сгенерированном из реестра. Ollama не требуется.

```bash
python3.10 ragas_test/evaluate_rag.py
```

Метрики:
- **BLEU Score** — n-gram перекрытие ответа с эталоном
- **Semantic Similarity** — косинусное сходство эмбеддингов ответа и эталона

Результаты сохраняются в `ragas_test/results.json`.
