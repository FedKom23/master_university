## 2. Ключевое изменение: замена LLM

### 2.1 Проблема

При тестировании baseline-версии выявлены критические недостатки локальной модели **Llama 3.1 8B**:

| Проблема | Пример |
|----------|--------|
| Низкое качество русского языка | Грамматические ошибки, неестественные конструкции |
| Избыточная генерация | Ответ на простой запрос избыточен |
| Галлюцинации | Выдумывание несуществующих постановлений |


### 2.2 Решение

Переход на **Qwen 2.5 7B Instruct** через HuggingFace Inference API.

**Обоснование выбора:**
- Qwen 2.5 обучен на качественных русскоязычных данных
- Компактные и точные ответы без "воды"
- Бесплатный доступ через HuggingFace (rate limits достаточны для MVP)
- Не требует локальных вычислительных ресурсов

### 2.3 Реализация
Теперь нужен токен на HuggingFace:

```env
# .env
HF_TOKEN=hf_xxxxxxxxxxxxxxxxxxxxxxxxx
```
