# 👥 Анализ целевой аудитории


> Исследование потенциальных пользователей сервиса ФармКонтроль
>
> ## 1. Общая идея продукта

Фармконтроль - это цифровой сервис (web/mobile), который позволяет проверить,
не превышает ли цена лекарственного препарата в аптеке предельно допустимую,
установленную Минздравом РФ.

Продукт использует данные государственного реестра предельных отпускных цен
и LLM + RAG для поиска и интерпретации нормативной информации.

---

## 2. Сегментация целевой аудитории

### 2.1. Основной сегмент - физические лица (B2C)

#### 1) Социально уязвимые группы
- Пенсионеры
- Люди с хроническими заболеваниями
- Родители маленьких детей
- Люди с низким уровнем дохода

Боли:
- Недоверие к аптекам
- Непонимание, регулируется ли цена
- Сложность проверки информации вручную
- Риск переплаты

Потребность:
Простая проверка «здесь и сейчас» - справедлива ли цена.

Платежеспособность:
Низкая или средняя. Вероятная модель - freemium или бесплатный социальный сервис.

---

#### 2) Рациональные потребители
- Люди 25-45 лет
- Пользуются цифровыми сервисами
- Сравнивают цены

Боли:
- Отсутствие прозрачности регулирования
- Нет удобного способа проверить соответствие нормативам

Платежеспособность:
Средняя. Возможна подписочная модель с дополнительными функциями.

---

### 2.2. Вторичный сегмент - профессиональные пользователи (B2B)

#### 1) Фармацевтические юристы
#### 2) Контролирующие органы
#### 3) Общественные организации по защите прав потребителей

Боли:
- Неудобный поиск по реестрам
- Необходимость ручной проверки нормативной базы

Ценность продукта:
- Автоматизация поиска
- Быстрое выявление нарушений

---

## 3. Проблема, которую решает продукт

1. Информационная асимметрия между аптекой и покупателем.
2. Сложность доступа к государственным данным.
3. Отсутствие понятного интерфейса для проверки соблюдения ценового регулирования.

---

## 4. Объем рынка (качественная оценка)

- Практически любой гражданин РФ является потенциальным потребителем лекарств.
- Более 70% населения покупают лекарства минимум несколько раз в год.
- Регулируемые препараты (ЖНВЛП) занимают значительную долю рынка.

Потенциальный охват - массовый.

---

## 5. Конкуренты
### Прямые конкуренты
Отсутствуют. Нет сервиса, который:
- Автоматически проверяет предельную цену
- Использует RAG + LLM для нормативного анализа

### Косвенные конкуренты
- Сайты сравнения цен
- Справочные порталы
- Ручной поиск в ГРЛС

---

## 6. Гипотезы для проверки

1. Пользователи действительно сталкиваются с превышением цен.
2. Пользователи готовы использовать мобильное приложение для проверки.
3. Фото-режим (камера + OCR) значительно повысит удобство.

---

## 7. Вывод

Продукт решает социально значимую проблему - прозрачность ценообразования
на регулируемые лекарственные препараты.

Основная аудитория - массовый B2C-сегмент, с дополнительным потенциалом B2B.
Проект имеет высокий общественный потенциал и может быть масштабирован
до мобильного приложения с функцией распознавания изображения.
