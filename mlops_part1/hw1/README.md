# ДЗ-1: bash

## Как сдавать решение и в какой срок

### Оценка
За задание можно получить 5 баллов, если сдать до Soft Deadline. После него, но до Hard Deadline -- половина баллов. После решение не оценивается.

### Дедлайны
**Soft Deadline - 26 февраля в 23:59.**

**Hard Deadline - 5 марта в 23:59.**

### Формат сдачи
1. Нужно завести ветку `hw1` и вести свою разработку там.
2. Свою реализацию пропишите в файле `hw1/solution.py`, для каждого таска надо вписать команду в соответствующую переменную.
3. Локально тесты можете запускать так (из корня репозитория):

    ```
   python -m pytest --log-cli-level INFO hw1/
   ```
4. Как только считаете, что решение готово, заводите Merge Request из ветки `hw1` в `master`.
5. Если с прошлым МР-ом что-то было не так и вы решили завести новый, закройте, пожалуйста, старый самостоятельно. Это делается на странице МР-а: Троеточие -> Close merge request.
6. Если пайплайн полностью проходит (все зеленное), бот отписал комментарий с баллами в ваш MR, ставьте в assignee `Владислав Ефимов`.
7. Profit!

## Задания
### 1. Подсчитать количество файлов в текущей папке (без директорий)
В текущей директории есть файлы и папки. Нужно вывести количество только файлов.

#### Пример

Содержимое директории:
```
a.txt
b.txt
c.sh
dir1/
dir2/
```

Ответ:
```
3
```

### 2. Найти 5 самых больших файлов
В текущей директории находятся файлы разного размера. Нужно вывести имена 5 самых больших.

#### Пример

Содержимое директории (в скобках указан размер):
```
a(1Kb)
b(20Kb)
c(5Kb)
d(15Kb)
e(7Kb)
f(50Kb)
```

Ответ:
```
f
b
d
e
c
```

### 3. Отсортировать строки в файле и убрать дубликаты
Есть файл `input.txt` с повторяющимися строками. Нужно сделать `clean.txt` с уникальными строками в алфавитном порядке.

Пример

input.txt
```
b
a
a
c
b  
```

clean.txt
```
a
b
c
```

### 4. Найти строки с ERROR в .log файлах
В текущей директории лежат .log файлы. Нужно вывести только уникальные строки в алфавитном порядке, содержащие ERROR.

#### Пример

В директории два файла `log1.log` и `log2.log`. 

log1.log
```
INFO ok
ERROR failed
ERROR failed
```

log2.log
```
ERROR crash
```

Ответ:
```
ERROR crash
ERROR failed
```

### 5. Найти все пустые файлы
В текущей директории есть файлы, некоторые из них пустые. Нужно вывести список пустых.

#### Пример

Содержимое директории (в скобках указан размер):
```
a.txt(0B)
b.txt(3B)
c.sh(0B)
```

Ответ:
```
a.txt
c.sh
```
